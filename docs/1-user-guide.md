# DocHub 使用手册

DocHub 是团队内部源码文档中心。系统从代码仓库同步 Markdown 文档，按项目和分支组织内容，支持目录浏览、全文搜索、文档下载以及基于用户或组织机构的读取授权。

本手册面向使用 DocHub 阅读文档、接入项目和管理权限的成员。

系统管理员的后台维护操作请参阅[《管理手册》](./2-admin-guide.md)。

## 1. 登录系统

打开 DocHub 地址后，可以使用以下方式登录：

- **本地账号登录**：输入管理员提供的用户名和密码，点击“进入文档中心”。
- **单点登录**：如果页面显示“使用 XXX 登录”，点击对应按钮并完成身份服务认证。

单点登录用户首次登录时会自动创建 DocHub 成员账号。新账号默认不属于任何组织机构，需要管理员分配组织或为项目单独授权后才能访问私有内容。

页头右上角可以切换日间/夜间模式、进入账号设置或退出登录。

## 2. 浏览项目

登录后默认进入“项目文档”页面。

- 列表视图适合查看更多项目字段和分支信息。
- 卡片视图适合快速浏览项目概况。
- 搜索框可以按项目名称、仓库地址、负责人、同步状态或分支名称筛选项目。

项目卡片或列表行中的状态包括：

- **待同步**：项目已接入，但尚未完成首次同步。
- **同步中**：系统正在拉取仓库和生成文档快照。
- **已就绪**：所有配置分支均已同步成功。
- **部分异常**：存在同步失败的分支，其他已成功分支仍可阅读。

点击项目即可进入文档阅读页。只能看到公开项目或已获得授权的私有项目。

## 3. 阅读文档

进入项目后，左侧显示文档目录，中间显示 Markdown 正文，右侧显示当前文档的标题导航。

### 3.1 切换分支

页头分支选择器用于切换文档版本。每个已跟踪分支都有独立快照，不同分支的内容和文档列表可能不同。

### 3.2 浏览目录和正文

- 点击左侧 Markdown 文件打开文档。
- 点击目录中的文件夹可以展开或收起子目录。
- 点击右侧标题可以快速跳转到对应章节。
- 正文中的相对图片、附件和跨文档链接会尽量保持在当前项目和分支内跳转。

窄屏设备上，可以使用“目录”“本页目录”按钮打开移动端导航。

### 3.3 搜索当前分支

点击页头“搜索”或使用 `Command/Ctrl + K` 打开搜索窗口。搜索范围包括当前分支中自己有权阅读的文档标题、路径和正文。

只获得单篇文档授权时，搜索结果和目录树只会显示相应的已授权内容。

### 3.4 下载文档

文档页提供“下载”按钮，可将当前 Markdown 原文保存到本地。下载权限与当前文档的阅读权限一致。

### 3.5 复制给 Agent

文档页的“复制给 Agent”按钮可以生成读取当前文档原文的 `curl` 命令，便于在 Cursor、Claude Code 等工具中使用。

使用前需要先在账号设置中创建 Agent 凭证。存在多个凭证时，页面会要求选择一个；只有一个凭证时会直接复制。

## 4. 接入新项目

在项目列表点击“接入项目”，填写以下信息：

1. **项目名称**：展示在项目列表和文档页中的名称。
2. **可见范围**：选择公开或私有。
3. **SSH 仓库地址**：填写 DocHub 服务可访问的仓库地址。
4. **文档目录**：填写一个或多个存放 Markdown 的目录，例如 `docs`、`design`。
5. **跟踪分支**：填写需要提供阅读快照的分支，例如 `main`、`release/1.0`。

点击“创建并同步”后，系统会异步克隆仓库并生成每个分支的文档快照。首次同步完成前，文档可能暂时不可读。

项目名称、仓库地址、文档目录和分支可以根据需要继续调整。

## 5. 查看和管理项目

项目创建人或系统管理员可以打开“项目管理”弹窗。普通成员只能阅读已获授权的内容。

### 5.1 修改项目配置

项目管理中可以修改：

- 项目名称
- 公开/私有可见范围
- SSH 仓库地址
- 文档目录

修改仓库地址或文档目录会清除原有文档快照，并自动重新同步所有已配置分支。仅修改名称或可见范围不会触发重新同步。

### 5.2 配置项目级读取权限

“项目级读取权限”可以同时授权给用户和扁平组织机构。

- 获得项目级权限后，可以读取该项目全部分支和全部文档。
- 组织成员授权与用户个人授权取并集。
- 用户被移出组织后，会立即失去由该组织带来的权限。
- 已有的个人授权不受组织成员变化影响。
- 项目创建人和系统管理员始终拥有完整读取和管理权限。

选择授权用户或组织后，需要点击“保存项目权限”。

### 5.3 管理分支

项目管理中会显示全部分支及其同步状态：

- **已同步**：当前快照可用。
- **同步中**：系统正在更新快照。
- **同步失败**：本次同步失败，系统继续展示上一份成功快照。
- **待同步**：分支已添加但尚未完成同步。

可以输入分支名称并点击“添加分支”。分支添加后会立即进入同步队列。

至少保留一个跟踪分支时，可以移除其他分支。移除只会删除 DocHub 中的本地快照，不会影响远端仓库。

### 5.4 手动同步

文档页头部的“同步”按钮用于更新当前分支。同步完成后，页面会刷新到最新提交。

同步失败时，系统会保留上一份成功快照，正文仍可继续阅读。管理员或项目创建人可以根据错误信息检查仓库访问和网络状态后重试。

### 5.5 删除项目

项目管理底部提供“删除项目”。删除后会清除 DocHub 中的项目数据、本地镜像和全部文档快照，但不会删除远端代码仓库。

该操作不可恢复，执行前需要二次确认。

## 6. 授权与可见范围

### 6.1 公开和私有

- **公开项目**：所有已登录用户都可以读取。
- **私有项目**：只有项目创建人、系统管理员以及获得项目级或文档级授权的用户可读。

公开不等于互联网公开，未登录访客不能访问文档。

### 6.2 文档级读取权限

打开某篇文档后，创建人或系统管理员可以点击“文档权限”进行单篇授权。

- 文档授权按仓库中的完整路径生效，并覆盖所有分支。
- 可同时授权给用户和组织机构。
- 获得文档权限后，可以读取该文档正文、下载原文，以及读取正文实际引用的图片和附件。
- 文档授权不允许读取同项目中的其他未授权文档。

项目级权限与文档级权限同时存在时，以能够访问更多内容的范围为准。

### 6.3 组织机构授权

系统使用扁平组织机构，组织之间没有上下级继承关系，一个用户可以加入多个组织。

- 将项目授权给组织后，组织中的所有直属成员获得项目读取权限。
- 将文档授权给组织后，组织中的所有直属成员获得该文档读取权限。
- 用户加入或退出组织后，权限立即变化。
- 删除组织会同时删除其成员关系，以及该组织带来的全部项目、文档授权。

组织授权只开放的读取能力，不会授予项目管理、分支同步或授权配置权限。

## 7. 账号设置和 Agent 凭证

点击页头个人头像进入“账号设置”。

### 7.1 修改密码

- 本地账号可以输入当前密码后设置新密码。
- 单点登录创建的账号初始没有本地密码，可以直接设置。
- 新密码至少 8 位。

设置本地密码后，仍可通过单点登录进入系统，也可以按需使用 HTTP Basic Auth 访问有权限的文档资源。

### 7.2 创建 Agent 凭证

在“Agent 凭证”页签中填写凭证名称和有效期，然后点击“创建凭证”。

凭证特点：

- 仅用于读取项目、目录、文档、搜索、下载和附件。
- 不能登录 Web，也不能执行修改、同步或授权等写操作。
- 权限实时跟随创建者当前的项目和文档权限。
- 登录后可以再次查看凭证原文，请勿公开发送。
- 可随时撤销；撤销后使用该凭证的 Agent 会立即失去访问权限。

建议为不同工具分别创建凭证，便于识别最近使用时间并单独撤销。

## 8. 常见问题

### 8.1 登录后看不到项目

可能原因：

- 项目是私有项目，当前账号没有项目或文档授权。
- 账号刚加入组织，但项目尚未授权给该组织。
- 项目仍在首次同步或同步失败，暂时没有可读文档。

请联系项目创建人或系统管理员确认可见范围与授权。

### 8.2 能进入项目，但目录为空或文档很少

私有项目只展示当前账号有权阅读的文档。若只获得单篇文档授权，目录树和搜索结果不会显示其他内容。

### 8.3 搜索不到某个文档

请先确认：

- 已切换到正确分支。
- 文档位于项目配置的 Markdown 目录中。
- 当前账号拥有该文档读取权限。
- 文档已经完成同步。

### 8.4 项目显示“同步失败”

系统会保留上一份成功快照，已同步内容仍可阅读。请确认远端分支、仓库地址和服务器访问权限，再点击文档页的“同步”重试。

### 8.5 看不到“管理”或“文档权限”按钮

项目管理、同步和授权配置只开放给项目创建人和系统管理员。组织成员或个人授权只提供文档读取能力。

### 8.6 Agent 提示无权限

Agent 凭证权限跟随创建者当前权限。请确认：

- 创建者仍拥有目标项目或文档权限。
- 凭证尚未过期或撤销。
- 请求的是已授权分支和文档路径。

如权限刚调整，直接重新请求即可，不需要重新创建凭证。

## 9. 使用建议

- 优先为团队维护稳定的组织机构，再以组织为单位授权项目。
- 对只需要查看少量文档的外部协作成员，使用文档级授权。
- 同步失败时先核对分支和仓库地址，不要立即删除项目。
- Agent 凭证按工具分别创建并设置合理有效期，不使用时及时撤销。
- 修改仓库地址或文档目录前，确认影响范围，因为该操作会清空快照并触发全部已配置分支重新同步。
